# Windows source and build tree

This folder is the **Windows source/review tree**, not the player release. The player package is
the separate `Rebloom-0.1-Windows-x86_64.zip` at the repository root; it contains only the runtime
and launcher, not this source.

- `source/` — the launcher (`Launcher.cs`, `Build-Launcher.ps1`), the recompiled C++ and the
  rebuild notes.
- `art/` — the launcher artwork.
- `game/` — the runtime shader and icon used when building the package.

Project overview and downloads: [`../README.md`](../README.md).
