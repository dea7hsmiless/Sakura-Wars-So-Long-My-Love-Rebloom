# Quiver Launcher artwork

Upload these from the app's **Artwork** section. Sizes follow the fields Quiver shows in its
developer portal.

| Quiver field | File | Size | Notes |
| --- | --- | --- | --- |
| Icon | `icon-1024.png` | 1024×1024 | Square app icon. `icon-512.png` and `icon.ico` are included as fallbacks. |
| Box art | `box-art-600x900.jpg` | 600×900 | Portrait artwork for library views. |
| Cover | `cover-920x430.jpg` | 920×430 | Wide cover for catalog cards and the app page. |
| Banner | `banner-3840x1240.jpg` | 3840×1240 | Text-free background. The transparent logo goes over it. |
| Logo | `logo-1280.png` | 1280×426 | Transparent title. |

`banner-1920x620.jpg` is an optional smaller banner for 1920-wide library layouts.

The artwork is derived from the project's key art and logo and is used only to identify this
non-commercial fan project. No game data is included.
